# Project Name : "PricingQuest"
## Frontface/Web Name : "GoldBarn"
This an internship project which required me to make a real-time gold and silver price indicator. The project should display and save prices of gold and silver at second intervals. Along with that, the project should also allow users to see if they should buy or sell. Furthermore, there should be a currency converter to make it easier for users to keep track of prices in their desired home country currencies. A graph is also added to visually show the price changes whether up or down. The technical tools required were Java, html, css, md and knowledge of json, electron and a bit of machine learning.

# Setup and installation steps

The main applications you'll need to run this project successfully is Java, Intellig (which is what I used to make this) and Node.js for electron.

# How to use the application 
The main componenents to manage running the application is backend and frontend. 

Note -> the project combine a Java backend with an Electron frontend.
